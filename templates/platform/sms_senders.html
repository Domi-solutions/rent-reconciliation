SMS senders
The name a tenant's phone shows a text as coming from. A property with its own registered name (e.g. MOWIN) sends under it, and its texts no longer start with the building name — the sender already says it. A name shared by several properties keeps the building name. Everything else is sent as {{ default_sender }}, starting with the building name.
Register the name with the SMS provider first. A name that is not approved makes every SMS for that property fail — receipts and sign-in codes included. Save it with a test phone number to check.
